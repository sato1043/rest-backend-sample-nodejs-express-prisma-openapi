# 変更差分レビュー用プロンプト（サンプル）

タスク

- 直近の変更差分をレビューし、以下の観点で問題点・改善点を指摘してください。

観点

- セキュリティ（入力バリデーション、認可、秘密情報の扱い）
- API 互換性（OpenAPI と実装の差異、後方互換性の破壊）
- DB マイグレーション影響（Prisma スキーマと移行の整合性）
- パフォーマンス（N+1、不要な I/O、計算量）
- テスト整合性（既存テストの意図、追加が必要なテスト）
- 運用性（ログ、メトリクス、エラーハンドリング）

補足

- 参照: README.md, openapi/openapi-root.yaml, prisma/schema.prisma
- 秘密情報や認証情報を含めないでください。
