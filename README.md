# rest-backend-sample

- これはポートフォリオのためのリポジトリです

  - 2022 年ごろのスクラッチです
  - 2025 年 10 月に Jetbrains Claude Agent で簡単にリファクタしました
  - ポートフォリオとして雰囲気・素養・方針を見せられれば幸いです
  - ミドルウェアが古くなり実際にはもう使えません
  - 今なら今のツールで、似た方針をとろうかと思います（あるいは現場合わせで）
  - すべて一般的な知識に基づきます

- REST API バックエンドサーバーのサンプルコードです

  - スキーマファースト開発構成を目論む
  - ミドルウェア nodejs/express/prisma/openapi
