Introduction

This API definition is intended to to be a good starting point for describing your API in

OpenAPI/Swagger format.

It also demonstrates features of the create-openapi-repo tool and

the Redoc documentation engine. Beyond the standard OpenAPI syntax, we use a few

vendor extensions.

OpenAPI Specification

The goal of The OpenAPI Specification is to define a standard, language-agnostic interface to REST APIs which

allows both humans and computers to discover and understand the capabilities of the service without access to source

code, documentation, or through network traffic inspection. When properly defined via OpenAPI, a consumer can

understand and interact with the remote service with a minimal amount of implementation logic. Similar to what

interfaces have done for lower-level programming, OpenAPI removes the guesswork in calling the service.

  • ログイン済み前提
  • ここで示すのはシーク法によるページネーションの定義例。シーク法はページジャンプをIDで計算するのでインフィニットスクロールでページネーションがずれない
  • ページナビゲートのパラメータ４種（page|pagePrev|pageNext|infinite）は、排他的なオプションで、同時指定時にエラーとする（openAPIは排他オプションを定義できないため実装時は注意）
    • ページ番号指定では（クエリー時点の表示内容に関わらず）クエリー時点のデータベースでそのページ番号の内容となる選択行を返す(のみ)
    • 前ページ送りでは現在ページの最終行を基準に（データベースでの行数の増減に関わらず）前ページのperPage件以下を返却
      1. ページ先頭行IDによりページ境界を計算（なお検索範囲は現在ページから前後10ページ程度でUIに表示が必要な範囲で）
      2. 現在ページ先頭行IDより前のページ境界のうちの最大値を選択
      3. 3.より後のperPage件を返却
    • 次ページ送りでは現在ページの最終行を基準に（データベースでの行数の増減に関わらず）次ページのperPage件以下を返却
      1. ページ後尾行IDによりページ境界を計算（なお検索範囲は現在ページから前後10ページ程度でUIに表示が必要な範囲で）
      2. 現在ページ後尾行ID 以前のページ境界のうち最大を選択
      3. 2.より後のperPage件を返却
    • 無限スクロールでは現在ページの後尾行IDより後のperPage件以下を返却
